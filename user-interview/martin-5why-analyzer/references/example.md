# 对话样例

> 示例数据为虚构，仅演示节奏与格式。真实对话中每轮只输出一个"为什么"。

## 第 1 轮

**用户**：今年 Q2，我们线上课程的老客户续费率从 45% 掉到 28%。

**顾问**：

```
**问题**：2026 年 Q2，线上课程老客户续费率从 45% 降至 28%。
**因果链**：暂无（待建立）
**校验**：问题陈述合格——有对象、有指标、有时间。
**下一个为什么**：为什么 Q2 老客户的续费率会从 45% 掉到 28%？
```

## 第 2 轮

**用户**：因为 Q2 我们把课程交付从直播改成了录播。

**顾问**：

```
**问题**：2026 年 Q2，线上课程老客户续费率从 45% 降至 28%。
**因果链**
1. 为什么续费率下降？ → Q2 课程交付由直播改为录播（事实）
**校验**：这是时间上的相关，还不能证明因果。有数据能说明改录播后完课率或满意度同步下降吗？
**下一个为什么**：为什么改成录播会导致老客户不愿续费？
```

## 第 3 轮

**用户**：录播没人监督，完课率从 70% 掉到 35%，学员觉得没学到东西。

**顾问**：

```
**问题**：2026 年 Q2，线上课程老客户续费率从 45% 降至 28%。
**因果链**
1. 为什么续费率下降？ → 交付由直播改为录播（事实）
2. 为什么录播导致不续费？ → 缺少监督，完课率 70%→35%，学习效果感下降（事实）
**校验**：通过。因果链已落到可观测指标。
**下一个为什么**：为什么改录播时没有配套的监督或督学机制？
```

## 第 4 轮

**用户**：因为当时是为了压缩成本，管理层直接拍板，没走课程设计评审。

**顾问**：

```
**问题**：2026 年 Q2，线上课程老客户续费率从 45% 降至 28%。
**因果链**
1. 为什么续费率下降？ → 交付由直播改为录播（事实）
2. 为什么录播导致不续费？ → 缺少监督，完课率 70%→35%（事实）
3. 为什么没有配套督学？ → 降本决策未走课程设计评审（事实，待验证）
**校验**：这条指向流程，不指向人，方向正确。需确认"未走评审"是否有会议记录或审批流可查。
**下一个为什么**：为什么降本决策可以绕过课程设计评审？
```

## 第 5 轮

**用户**：因为评审流程只覆盖新课上线，老课改版没有强制评审节点，也没人负责。

**顾问**：

```
**问题**：2026 年 Q2，线上课程老客户续费率从 45% 降至 28%。
**因果链**
1. 交付方式变更（事实）
2. 缺少督学，完课率下降（事实）
3. 变更未走课程设计评审（待验证）
4. 评审制度只覆盖新课，老课改版无强制节点（事实）
**校验**：满足根因三条件：不可再问、移除后问题不再复发、组织可控。
```

## 根因确认与对策

**「所以」测试**：因为评审制度只覆盖新课、老课改版无强制节点，所以降本决策绕过了课程设计评审；因为没有评审，所以改录播时没有配套督学；因为没有督学，完课率从 70% 掉到 35%；因为学习效果感下降，老客户续费率从 45% 降到 28%。

**根本对策**
- 把"老课交付方式变更"纳入强制评审节点，评审清单必须包含完课率与督学方案。
- 责任人：课程运营负责人；验证指标：改版课程评审覆盖率 100%；复盘节点：下一季度末。

**临时对策**
- 对已改录播的课程补建督学与社群提醒，观察 4 周完课率是否回升。

**复发预警信号**
- 老课改版未提交评审记录。
- 改版后 2 周内完课率低于 50%。
- 续费意向调研中"学习效果"负面提及上升。

**尚未验证的假设**
- "未走评审"目前来自用户口述，需用审批记录核实。
