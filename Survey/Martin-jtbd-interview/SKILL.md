## 工作流程

### Step 0 · 确认调研方向

用户说"做一次XX用户访谈"时，先确认：

1. **调研主题**：如"Vibe Coding工具"、"GEO写作平台"
2. **目标用户画像**：如"不懂代码的 Marketer"、"独立开发者"
3. **核心问题**：这次调研想回答什么问题？

---

### Step 1 · 生成虚拟访谈对象

用户可指定特征（性别/年龄/城市/职业/收入），也可说"随机生成"。

**输出格式：**
```
### 访谈对象 #N | [姓名]

| 字段 | 内容 |
|------|------|
| 姓名 | [随机姓名] |
| 性别 | 男/女 |
| 年龄 | XX岁 |
| 城市 | XX |
| 学历 | XX |
| 职业 | XX |
| 月收入 | X,XXX元 |
| 是否在职 | 在职/自由职业/学生 |

**背景故事：**
[2-3句话，交代为什么接触该领域、有哪些痛点]
```

---

### Step 2 · 执行访谈

读取 `references/interview-script.md` 中的访谈脚本，按 Part 0~4 结构提问。

**关键原则：**
- 以访谈员身份提问
- 代入虚拟人物背景和痛点，生成符合逻辑的回答
- 重点记录：关键金句、放弃原因、付费意愿

---

### Step 3 · 填写结构化记录（27字段）

访谈结束后，将访谈内容映射到以下 27 个字段：

```
行1:  姓名
行2:  基本画像
行3:  访谈状态
行4:  待办任务
行5:  现有状态
行6:  [分类标题] 改变的力量
行7:  触发事件（Triggering Event）
行8:  转换触发事件（Conversion Event）
行9:  期望结果
行10: 利益攸关的问题
行11: [分类标题] 吸引力
行12: 客户纳入考虑范围的解决方案
行13: 最终选择的解决方案
行14: 独特价值主张（承诺的结果）
行15: 预期结果
行16: [分类标题] 改变现状所面对的阻力
行17: 现有解决方案（如果没有则不填）
行18: 哪里出了问题？
行19: 发生转换的障碍
行20: [分类标题] 使用最终选择的解决方案所面对的阻力
行21: 客户的焦虑
行22: 采用解决方案的障碍
行23: 其他细节（如果没有则不填）
行24: [分类标题] 下一步计划
行25: 时间轴
行26: 实际结果
行27: 下一步行动
```

---

### Step 4 · 生成 JSON 数据文件

JSON 的 key 必须与以下完全一致（23个数据字段，不含分类标题行）：

```json
{
  "姓名": "[访谈对象姓名]",
  "基本画像": "[性别+年龄+职业+城市+收入一句话描述]",
  "访谈状态": "✅ 已完成访谈",
  "待办任务": "[用户最想解决的问题，一句话]",
  "现有状态": "[当前的生活方式、使用条件]",
  "触发事件": "[最初接触该领域的契机]",
  "转换触发事件": "[真正下定决心尝试的原因]",
  "期望结果": "[希望达到的理想状态]",
  "利益攸关的问题": "[不解决的代价]",
  "客户纳入考虑范围的解决方案": "[尝试过的所有方法]",
  "最终选择的解决方案": "[最终用什么方式]",
  "独特价值主张": "[现有方案的承诺结果]",
  "预期结果": "[对最终方案的期待]",
  "现有解决方案": "[目前还在用的产品]",
  "哪里出了问题": "[放弃/不持续的核心原因]",
  "发生转换的障碍": "[为什么不切换新方案]",
  "客户的焦虑": "[对产品的担忧]",
  "采用解决方案的障碍": "[使用产品的实际困难]",
  "其他细节": "[补充信息]",
  "时间轴": "[关键时间节点]",
  "实际结果": "[目前实际状态]",
  "下一步行动": "[未来打算]"
}
```

> **注意：** JSON 中无需包含分类标题（行6/11/16/20/24），脚本会自动插入。

---

### Step 5 · 运行脚本追加到 CSV

执行以下命令，将 JSON 数据追加到横向 CSV 汇总表：

```bash
python3 ~/.workbuddy/skills/Martin-jtbd-interview/scripts/append_research.py <json文件路径> --topic "<调研主题>"
```

**CSV 横向结构：**

| 行 | A列（字段/分类） | B列=姓名1 | C列=姓名2 | D列=姓名3 |
|----|-----------------|-----------|-----------|-----------|
| 1  | （空白） | 姓名1 | 姓名2 | 姓名3 |
| 2  | （空白） | 基本画像 | ... | ... |
| ... | ... | ... | ... | ... |

**规则：**
- 首次执行 → 创建新 CSV（A列=字段名/分类标题，B列=第一人）
- 后续执行 → 自动追加到第一个空列
- CSV 路径：`{主题}访谈记录/{主题}访谈汇总.csv`
- CSV 使用 UTF-8 BOM 编码，Excel 双击打开不会乱码

---

### Step 6 · 保存 Markdown 全文

将完整访谈记录保存到：

`{主题}访谈记录/{主题}访谈记录_YYYYMMDD.md`

**Markdown 结构：**
```markdown
# {主题}用户访谈记录

## 目录
| 序号 | 访谈对象 | 日期 | 标签 |
|------|----------|------|------|
| 01 | [姓名] | YYYY-MM-DD | [标签] |

---

## 访谈 #N | [姓名]

### 基础信息
### 背景故事
### Part I · 现状
### Part II · 问题（关键金句）
### Part III · 解决方案
### Part IV · 收尾
### 访谈总结
### 访谈员笔记
```

同时更新目录表（追加新行）。
