# 多元宇宙事前推演方法参考

## 一、这个方法的本质

事前验尸（Premortem）先假设事情已经失败，再倒推失败原因，绕开"我们已经决定了，所以倾向于找支持证据"的确认偏误。

多元宇宙只是把这个过程拆成三条独立的失败路径：

- 同一个决策；
- 三个不同的平行宇宙；
- 每个宇宙只让一条关键假设失效；
- 看它如何一步步走向失败。

三个宇宙不是三个"可能的风险点"，而是三条完整的、互不依赖的失败故事。

## 二、假设分类

列假设时，至少覆盖以下五类中的三类：

| 类别 | 典型假设 | 失效后的表现 |
|---|---|---|
| 需求 | 用户真的需要、愿意付费、需求频率足够 | 没人买、复购低、获客成本高 |
| 能力 | 团队能交付、技术能实现、供应链跟得上 | 延期、质量崩、成本失控 |
| 竞争 | 对手不会快速跟进、价格能维持 | 价格战、份额被抢、差异化消失 |
| 时机 | 市场窗口还在、政策不会变、季节合适 | 进入太早或太晚、红利消失 |
| 组织 | 决策能执行、部门能协同、激励对齐 | 内耗、执行走样、关键人离职 |

## 三、构造一个失败宇宙

每个宇宙按五步写：

1. **设定条件**：明确这个宇宙里哪条假设不成立。
2. **触发事件**：写一个具体的、可能真实发生的事件作为起点。
3. **传导机制**：写清它如何影响下一个环节，至少两层传导。
4. **关键转折**：指出哪一个时间点本可以止损，但没有。
5. **失败结局**：给出可观察的失败状态，而不是"失败了"三个字。

## 四、质量检查

- 三个宇宙的失败机制是否真的不同？
- 每个宇宙是否对应一条不同的假设？
- 失败链条是否每一环都能解释"为什么下一步会发生"？
- 是否出现了"执行不到位""运气不好"这类空话？
- 是否把假设中的数据写成了事实？
- 故事是否在制造焦虑，而不是帮助决策？

任何一项不合格，重写对应宇宙。

## 五、常见陷阱

| 陷阱 | 表现 | 纠正 |
|---|---|---|
| 三胞胎 | 三个宇宙都是"没人买" | 换成需求、能力、竞争三条不同路径 |
| 万能背锅 | 失败原因都是"团队执行力差" | 追问机制：哪个流程、哪个决策节点出了问题 |
| 跳步 | 从"定价高"直接跳到"公司倒闭" | 补上中间环节：销量、现金流、续约 |
| 假数据 | 写"市场下降 37%"却没有来源 | 改成"假设市场下降约三成"，或标待验证 |
| 恐吓式叙事 | 每个宇宙都以灾难收尾，没有可行动信息 | 收束到一条可验证假设和一个低成本动作 |
| 宿命论 | 暗示无论怎么做都会失败 | 强调条件变化，而不是命运 |

## 六、收束方式

三个故事讲完后，不要停在"你要小心"。

- 把三条隐含假设改写成更稳健的表述；
- 选出最该优先验证的一条（发生概率高 × 影响大 × 验证成本低）；
- 给一个能在短期内完成的最小验证动作。

这样，事前验尸才从"吓人"变成"可行动"。
