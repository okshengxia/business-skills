# 输出样例

> 示例仅演示格式与颗粒度，内容为虚构场景，不含真实数据。

**用户提案**：把公司现有的线下训练营全部搬到线上，定价 999 元，靠低价快速放量。

```
<summary>
你计划把线下训练营整体线上化，以 999 元低价换取规模，用销量弥补单价下降，核心目标是快速做大盘子。
</summary>

<contrarian_assessment>
- 关键假设（Key Assumptions）：
  1. 线上转化率能接近线下——若不成立，低价带来的增量覆盖不了获客成本，放量即放亏。
  2. 999 元对应的人群与原有客户重叠——若线上吸引的是价格敏感的新客，原有高客单客户会流失，营收结构反而恶化。
  3. 训练营的核心价值可被线上交付——若价值主要来自同伴压力与现场反馈，线上完课率会崩，口碑随之崩。

- 盲区与风险（Blind Spots & Risks）：
  1. 价格锚定效应：999 元一旦成为公开价，未来恢复高价会被用户视为涨价，而非升级。
  2. 交付成本被低估：线上看似边际成本低，但助教、答疑、社群运营是随人数线性增长的人力成本。
  3. 竞争反应：低价策略最容易被复制，先发者拿不到结构性优势，只会把品类拖入价格战。

- 反向观点 / 替代策略（Alternative Perspectives）：
  1. 不做"低价放量"，做"高价小班"：同样规模下营收更高，且保住品牌位置；先验证线上交付质量，再谈规模。
  2. 分层而非替代：线下保留高客单旗舰营，线上做 199-299 元的轻量入口，用入口筛选后再升级，避免左右手互搏。

- 风险缓解与优化建议（Mitigation & Strengthening Strategies）：
  1. 先跑一期 50 人付费试点，观察完课率、续费意向、退款率三个信号，再决定是否放量。
  2. 设定止损线：若完课率低于 60% 或退款率高于 15%，停止扩张并回到交付设计。
  3. 价格分层前先做老客户访谈，确认 999 元不会冲击原有客单，避免沉默流失。
</contrarian_assessment>

<confidence_score>58%｜依据：方向可能成立，但"线上转化率"与"交付价值可线上化"两条关键假设均未验证，且价格锚定的长期代价被忽略。</confidence_score>
```
