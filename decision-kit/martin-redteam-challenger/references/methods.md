# 红队方法库

按想法的类型与失败代价选择方法，通常用 1-2 种即可，不必全上。

## 1. 事前验尸（Premortem Analysis）

**适用**：已有明确行动方案，需要评估执行风险。失败代价高、不可逆时优先。

**步骤**：
1. 设定时间点：「假设 12 个月后这件事彻底失败。」
2. 不问"为什么会失败"，而问"它是怎么死的"——逼出具体死因。
3. 列出 3-5 个最可能的死因，按「发生概率 × 破坏力」排序。
4. 对每个死因写一条早期预警信号。
5. 只保留前 2-3 个死因进入"盲区与风险"。

**输出钩子**：死因 → 盲区与风险；预警信号 → 缓解建议。

## 2. 反方推理（Devil's Advocate Reasoning）

**适用**：方案看起来顺理成章、团队共识过强、缺少反对意见时。

**步骤**：
1. 找出方案成立所依赖的最强假设，而不是最弱的那条。
2. 站在"聪明且善意的反对者"立场，写出他为什么不买账。
3. 检查反方观点能否独立成立：换一个人、换一份数据，是否仍然说得通。
4. 把反方观点升级为替代策略，而不是停在"我不同意"。

**输出钩子**：最强假设 → 关键假设；反方立场 → 反向观点 / 替代策略。

## 3. 第一性原理（First Principles Thinking）

**适用**：方案建立在行业惯例、类比或他人经验上，底层逻辑可能不成立时。

**步骤**：
1. 把方案拆成不可再分的事实：用户需求、成本结构、渠道约束、竞争反应。
2. 逐条追问「这是事实，还是惯例/推断？」
3. 从事实重新推导：如果从零开始，最小可行路径是什么？
4. 对比原方案与新路径，找出被继承下来的隐性成本。

**输出钩子**：惯例 vs 事实 → 关键假设与盲区；新路径 → 替代策略。

## 4. 事实核查纪律

- 涉及市场规模、竞品动作、政策法规、技术能力时，先查证再评判。
- 无法查证的内容标「待验证」，并说明它若为假会推翻哪条结论。
- 不使用模糊来源（"数据显示""业内普遍认为"）充当证据。
